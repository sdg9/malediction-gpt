# Contributing

This project is released into the public domain under The Unlicense, so contributions are welcome from anyone!

## How to Contribute

1. Fork the repository
2. Make your changes
3. Test your changes
4. Submit a pull request

## Types of Contributions Welcome

- Bug fixes
- Feature improvements
- Documentation updates
- Code optimizations
- Support for additional PDF formats

## No Formal Process Required

Since this is public domain software, there's no formal contribution agreement needed. Just submit your improvements and they can be merged!

## Questions?

Feel free to open an issue if you have questions or suggestions.
