## [1.0.0] - 2025-06-23

### Added

- Initial release of PDF to text converter
- Auto-detection of all PDF files in input directory
- Page marker preservation in output files
- Error handling and progress reporting
- Comprehensive documentation and setup instructions
- Public domain license (The Unlicense)
- Contributing guidelines

### Features

- Processes all PDF files in `input/` directory automatically
- Preserves original filenames with `.txt` extension
- Creates output directory automatically
- Supports both `.pdf` and `.PDF` extensions
- Graceful error handling for individual files
- Progress reporting and conversion summary
